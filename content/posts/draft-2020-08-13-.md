\#\#\#\# Encoder Data {.wp-block-heading}

Encoder data must be collected, the more frequently this occurs, the higher the resolution of the plot will be. I have found that fixed time intervals works well. The data must be ***relative*** to the last reading ie. the difference in counts over the last time period (or since the last reading was stored).

For example, if the robot is travelling in a straight line, the below table illustrates values one may expect to see:

|                            |                          |
| -------------------------- | ------------------------ |
| **Constant speed Example** | **Acceleration Example** |
| 10, 10                     | 5, 5                     |
| 10, 10                     | 10, 10                   |
| 10, 10                     | 15, 15                   |
| 10, 10                     | 20, 20                   |

This information may be stored in any number of ways depending on connectivity:

  - USB Cable
      - Print over Serial Port at each fixed time interval
      - Store in array and print when connected to Serial port
  - Bluetooth UART
      - Print over Serial Port at each fixed time interval
  - WiFi
      - Print over Socket at fixed time intervals

When printing to a terminal window, the values may be copied and pasted into a text file for the Python program to plot.

However, the WiFi data collection may be streamed directly over a Socket to the Python plotting program to see a ‘live’ route on the screen.

\#\#\#\# Python – Turtle Graphics {.wp-block-heading}

Python 3.\# distributes with a Turtle Graphics library, which enables graphics to be generated in much the same way other Turtle software did ([see official documentation here](https://docs.python.org/3/library/turtle.html#:~:text=The%20turtle%20module%20is%20an,\)%20100%25%20compatible%20with%20it.)). UKMARSbot may be considered a ‘turtle’ for it can move fwd and reverse, and rotate left and right. Such a direct comparison makes for a very simple way to convert real-life movement to onscreen movement. A basic install of Python 3.\# is all that is required for the program to work. See the below code for a basic example, the plot function draws a line given the left and right encoder counts.

```
import turtle               #Included with Python 3.# installation
import math

screen = turtle.getscreen() #Create a screen to draw track on
robot = turtle.Turtle()     #Create instance of Turtle (robot in our case)

################Robot Settings################
A = 118               #A = Wheel Separation in Encoder counts (approx. 118 for UKMARSbot)

################Draw Path################
def plot(lCount, rCount):
    arcLength = (lCount+rCount)/2
    angleTurned = (lCount-rCount)/A
    angleTurned = (angleTurned*180)/math.pi     #Convert from Radians to degrees
    for i in range (5):            #Plot section in ten straight lines
        robot.fd(arcLength/5)
        robot.rt(angleTurned/5)

plot(100, 100)
plot(100, 50)
```
