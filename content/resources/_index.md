In this section you will find guides for locating hardware resources and suppliers; installing and using software tools and for some articles about various subjects relevant to robotics and microcontrollers

## UKMARS  {#UKMARS}

We have dozens of pages packed with information about the two UKMARSBOT robots and related items at our projects pages [here](/projects/)

## Github {#Github}

The definitive reference resource for detailed information about the PCB boards and software for UKMARSBOT is on Github at <https://github.com/ukmars> Look in the ukmarsbot repository for lots of details about the robot itself.

## Hardware {#Hardware}

We have a page packed with links to [Hardware and Suppliers](/resources/hardware-and-suppliers/)

## Software {#Software}

If you are using the Arduino IDE for your robot, have a look at the [Arduino Notes](/resources/arduino-notes/).

An alternative to the Arduino IDE is PlatformIO. Find out how to install it [here](/resources/platformio-vscode-windows/).
