## GETTING STARTED {#GETTING_STARTED}

We are mostly about building robots and running them in contests. To support roboteers who want to build a first robot capable of taking part in all the contests that we run, take a look at our 2 starter robot projects and supporting items in our “make one” guides below.

#### GEMINI {#GEMINI}

Our latest design, GEMINI, is a flexible robot aimed at education. It uses the Raspberry Pi Pico processor and can be programmed in micropython. Or, use your own processor board.

[Make One](/ukmars/wp-content/uploads/2026/09/GeminiBuildGuideDraft2.pdf)

#### UKMARSBOT {#UKMARSBOT}

Using inexpensive, easy to find parts, this robot needs only basic skills. Good for line following, pursuit racce, wall following, drag race, mini-sumo and even micromouse maze solving. Several processor versions are available and supporting multiple programming languages

[Make One](/projects/ukmarsbot/ukmarsbot-build-guide/)

#### Maze Timer {#Maze_Timer}

The maze timer is suitable for all of the maze based challenges including micromouse, wall following and time trials

[Make One](/projects/maze-timer/)

#### Line Follower Timing {#Line_Follower_Timing}

The line following and drag race challenges need a different kind of timing gate than the maze. These are generally gantry-style systems.

[Make One](https://github.com/ukmars/timing-system)

#### Maze Building {#Maze_Building}

If you are going to build a micromouse that runs in a maze then you will want to build your own maze for practice. We have a basic guide for building a practice maze here.

[More](/projects/maze-construction/)

#### Sensor Blaster {#Sensor_Blaster}

The Sensor Blaster is a simple device that emits pulses of light strong enough to interfere with maze timer sensors. It is used to test the timers and could be useful for testing micromouse sensors as well.
