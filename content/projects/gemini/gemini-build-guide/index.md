The Gemini version of UKMARSBOT is designed for use with the various different processors. There are 4 printed circuit boards (PCBs) in the set. A main chassis board, a mezzanine board and 2 sensor boards, one for line sensing and one for wall sensing. The main chassis board and the 2 sensor boards are common to all the different processors, but the mezzanine board is tailored to a specific processor board. The [GeminiBuildGuide](/ukmars/wp-content/uploads/2026/09/GeminiBuildGuideDraft2.pdf) describes the whole build process for a GEMINI robot using a mezzanine board for the Raspberry Pi Pico or Pico W processor board.
